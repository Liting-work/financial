## 需要留意的差异

`02-每刻接口对接文档.md` 是接口提供方给的原文，实测有几处与实际不符或有遗漏，以代码注释和实测为准：

| 文档写的 | 实测情况 |
|---|---|
| 基础地址 `http://<服务器>:17073` | 该地址不可达，实际用网关 `https://train.aojuai.com/ajdataother` |
| 未提及单据号字段区别 | `detail`/`expense-list`/`process-log` 只能传 `formCode`，传 `formDataCode` 会返回 `每刻返回异常: ACK` |
| 未说明费用金额字段 | 费用行金额是 `consumeBaseAmount` |
| 未说明借款字段含义 | `tradeStatistics.tradeAmount` 是**笔数**，真实金额在 `monetaryInfoList` |

MCP 接入一节（文档第 5 节）仍然有效，适用于 Cherry Studio 等客户端，无需 Key。
