# 每刻财务只读查询接口对接文档

面向：北京市财务。

## 1. 概述

提供 5 个**只读查询**能力（与每刻页面信息一致）：报销列表、报销详情、费用明细、审批流程、员工借款余额。

- 数据来自每刻开放平台，只能查询，没有提交/审批/删除等任何写操作
- 访问凭证 `X-Api-Key` 由系统管理员发放，一码一人，遗失/换人联系管理员更换
- 支持两种用法：①系统/脚本直接调 HTTP 接口（本文 3-4 节）；②AI 助手对话式查询（本文 5 节）

## 2. 通用约定

- 基础地址：`http://<服务器>:17073`（生产经网关时为 `https://train.aojuai.com/ajdataother`）
- 请求方式：全部 `POST`，`Content-Type: application/json`
- 鉴权：请求头 `X-Api-Key: <管理员发放>`；无效返回 HTTP 401
- 返回结构：`{"status":200, "result":"success", "msg":"成功", "data":...}`；失败时 `status=201`，`msg` 为原因
- `data` 为每刻原始数据：金额是对象 `{"amount":2981.05,"currency":"CNY"}`，时间为 13 位毫秒时间戳
- 时间查询参数一律 13 位毫秒时间戳（10 位秒级不支持），起止成对传入，跨度不能超过 366 天

## 3. 接口清单

### 3.1 报销单列表 `POST /meike-finance/reimburse/list`

对应页面：报销列表。不传任何时间参数时默认查创建时间近一年。

入参（均可选）：

| 字段 | 类型 | 说明 |
|---|---|---|
| createdAtStart/End | Long | 创建时间区间（起含止不含） |
| submittedAtStart/End | Long | 提单时间区间 |
| approvedAtStart/End | Long | 审批通过时间区间 |
| updatedAtStart/End | Long | 修改时间区间 |
| settledAtStart/End | Long | 支付时间区间 |
| auditedAtStart/End | Long | 审核时间区间 |
| formStatus | String | APPROVING审批中/AUDITING审核中/SIGNING签收中/SETTLEMENT结算中/COMPLETED已完成/DELETED已删除/ABANDON已废弃/REJECTED已驳回/SUBMIT_FAILED提交失败/DRAFT草稿 |
| formCodes | List\<String> | 单据号列表，≤10 |
| coverUserList | List\<String> | 承担人工号（每刻工号），≤5 |
| fillUserList | List\<String> | 填单人工号（每刻工号），≤5 |
| legalEntityBizCodes | List\<String> | 公司抬头编码，≤10 |
| formSubTypeBizCode | String | 单据小类编码 |
| exportStatus | Integer | 0-未导出 1-已导出 |
| pageNo / pageSize | Integer | 默认 1 / 100，pageSize 最大 100 |

返回 `data`：`{hasNextPage: boolean, list: [报销单...]}`，按创建时间倒序。

```bash
curl -X POST http://127.0.0.1:17073/meike-finance/reimburse/list \
  -H "Content-Type: application/json" -H "X-Api-Key: <你的Key>" \
  -d '{"createdAtStart":1790000000000,"createdAtEnd":1790800000000,"pageNo":1,"pageSize":20}'
```

### 3.2 报销单详情 `POST /meike-finance/reimburse/detail`

入参：`formCode`（单据号，必填）；开关（默认 false）：`enableAttachments` 附件、`enablePayeeInfo` 收款账户、`enableTravelRouteList` 行程、`enableAssociatedFormList` 关联单据、`enableTravelPartnerInfo` 参与人、`enableDatahubBillList` 月结账单。费用列表/发票列表/费用分摊默认返回。

### 3.3 费用明细 `POST /meike-finance/reimburse/expense-list`

入参：`formCode` 必填。返回单据汇总字段（单号/人员/部门/法实体/金额/状态）+ `expenseList`（费用+发票+分摊）。

### 3.4 审批流程 `POST /meike-finance/reimburse/process-log`

入参：`formCode` 必填。返回 `data.openApiFormProcessLogs`：节点名、类型（审批/抄送/审核/支付…）、操作人、操作记录、审批意见、操作时间。

### 3.5 员工借款余额 `POST /meike-finance/loan/employee-balance`

入参：`employeeNos`（每刻工号列表，必填，≤20）。返回每人借款笔数/类型/金额（在途借款单不计入，已还款金额已剔除）。

## 4. 常见问题

| 现象 | 原因与处理 |
|---|---|
| HTTP 401 | Key 无效或已更换，联系管理员 |
| "时间跨度不能超过366天"等提示 | 按 msg 调整入参 |
| 查询偏慢 | 每刻平台限流（企业共享 10 次/秒），稍后重试即可 |

## 5. AI 助手接入（MCP，推荐）

使用支持 MCP 的 AI 客户端（Cherry Studio 等）时，不用写代码，在聊天窗口直接说"查一下工号 xxx 的借款余额""上个月深圳傲举的报销单拉个清单"即可。

配置（设置 → MCP 服务器 → 添加）：

- 类型：**MCP Streamable HTTP**（旧客户端选 SSE）
- URL：**`http://<服务器>:17073/meike-finance-mcp/mcp`**（生产经网关：`https://train.aojuai.com/ajdataother/meike-finance-mcp/mcp`）
- 无需 Key，其他留空

保存后自动出现 5 个工具：报销列表 / 报销详情 / 费用明细 / 审批流程 / 借款余额。日期直接说"2026-11-01"这样的格式即可。
